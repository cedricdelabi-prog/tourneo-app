# Tourneo V0.3

Cette version ajoute :

- ajout des équipes sous forme de cartes ;
- choix d'un emoji ;
- choix d'une couleur ;
- prise ou sélection d'une photo ;
- affichage des avatars dans les matchs et le classement ;
- sauvegarde automatique locale.

## Installation

Copier les dossiers `app`, `components`, `lib` et `types` à la racine du projet Next.js.
